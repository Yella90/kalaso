# Bamanankan : choix à faire valider

Le texte complet de l'interface est dans `lib/i18n/bm.ts`. C'est un **brouillon** : un enseignant ou un traducteur bambarophone doit le relire.
Les titres des chapitres et le contenu des leçons restent en français pour l'instant.

Points à vérifier aussi :
- les phrases longues (accroche de l'accueil, notes du programme) : naturel et niveau de langue ;
- l'usage de « i » (tu) pour s'adresser à l'élève ;
- le pluriel après un nombre (« 12 sapitiri » ou « 12 sapitiriw ») ;
- les tons : le dictionnaire les note (*kìsɛ*, *wàlànda*), l'interface ne les écrit pas, comme l'orthographe scolaire courante.
