# Bamanankan : choix à faire valider

Le texte complet de l'interface est dans `kalanso/lib/i18n/bm.ts`. C'est un **brouillon** : un enseignant ou un traducteur bambarophone doit le relire.
Les choix ci-dessous sont ceux qui demandent une décision. Les titres des chapitres et le contenu des leçons restent en français pour l'instant.

| Français | Brouillon | Choix à valider |
|---|---|---|
| Mathématiques | Jatebɔ | Le terme utilisé dans les écoles bilingues ? |
| Physique / Chimie / Biologie | Fizik / Simi / Biyolozi | Emprunts adaptés, ou termes bambara ? |
| Atome, électron, proton, neutron | atɔmu, ɛlɛkitɔrɔn, prɔtɔn, nɛtrɔn | Orthographe des emprunts |
| Élément (chimique) | ɛlɛman | Emprunt ; « fɛn » est trop vague |
| Noyau | kisɛ (« graine ») | Image juste, ou emprunt « nwayo » ? |
| Couche électronique | ɛlɛkitɔrɔn kuci | « kuci » vient de « couche » |
| Tableau périodique | Ɛlɛmanw tabulo | « tableau des éléments » |
| Famille (d'éléments) | denbaya | Image de la famille |
| Cours / Simuler / S'exercer / Appliquer | Kalan / Lajɛ / Degi / Waleya | Noms des 4 étapes, affichés partout |
| Le piège | Jaan | Le sens « piège » est-il clair pour un élève ? |
| Définition / Exemple | Kɔrɔ / Misali | |
| Aventure | Taama | « voyage » |
| 7e année | 7nan san | Usage scolaire réel ? |
| Programme officiel | Minisiri ka porogaramu | |
| Trimestre / heure | trimɛsiri / lɛri | |
| Noms des familles chimiques | Metali alikalinw, Gazi nɔbiliw… | Emprunts : à garder en français ? |

Points à vérifier aussi :
- les phrases longues (accroche de l'accueil, notes du programme) : naturel et niveau de langue ;
- l'usage de « i » (tu) pour s'adresser à l'élève ;
- les accords des pluriels en -w après les nombres (« 12 sapitiri » ou « 12 sapitiriw »).
